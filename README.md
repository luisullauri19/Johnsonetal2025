# Interception History – Code Repository

This repository contains all the MATLAB scripts and documentation associated with data analysis and figure generation for the publication:

**Johnson et al. (2025). Experimental Confirmation of the Interception History Paradigm for Colloid Transport in Porous Media**  
*Environmental Science & Technology*  
DOI: [10.1021/acs.est.5c03239](https://doi.org/10.1021/acs.est.5c03239)

---

## Repository Structure

### `/Scripts/`  
Contains all MATLAB scripts used for:
- Data loading and filtering
- Velocity-separation distance analysis
- Visualization and figure generation

### `/Script_Manual/`  
A PDF document describing each script, its function, and how to execute the workflow step by step.

---

## How to Use

1. Clone or download this repository.
2. Open MATLAB and navigate to the `/Scripts/` folder.
3. Follow the instructions in the PDF manual located in `/Script_Manual/` to run the analysis pipeline or reproduce figures.
